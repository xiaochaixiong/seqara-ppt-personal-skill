# 有据可查的数据图表

先决定听众要回答的问题，再决定图形。趋势回答“何时变化”，同期比较回答“谁高谁低”，排名回答“资源集中在哪里”，构成回答“整体由什么组成”，目标进度回答“实际距离目标还有多少”。材料只给一个总数时，优先用原生大数字页；没有可靠分母、基期或目标，就不画占比、增长或进度。

图形只有被口径卡支撑才可上屏：指标名称、统计总体、单位、时期、实际/目标/估计身份、来源表及位置、必要的分母和计算规则。先用 [数据合同](data-contract.md) 生成 `data_sources` 和 `metrics`，用 `check-data` 检查单元格与运算，再决定图表。图上的结论还要人工核对，不以数字一致代替论证成立。

## 原生可编辑图表

`data_chart` 可放在无现有原生图表的参考页。常用参考4页：沿用模板品牌占位、PART、标题、结论与来源脚注；只替换图形区域。支持以下五类，均内嵌 PowerPoint Data 工作簿，校验图表缓存与单元格一致：

| `type` | 图形 | 最适合的内容 | 额外约束 |
| --- | --- | --- | --- |
| `trend` | 折线 | 有序时间点及变化方向 | 每序列至少2个不同指标时期 |
| `comparison` | 分组柱 | 两个或多个可比系列 | 图例须明确年份/对象，不能只写“本期/对照期” |
| `ranking` | 横条 | 同一时期的类别高低 | 一序列，数值降序 |
| `composition` | 环形 | 同一总体的互斥组成 | 一序列、最多6类、同一时期、非负且总和大于零；人工核对是否穷尽总体 |
| `target_progress` | 实际/目标横条 | 同一时期的执行进度 | 两序列；指标有 `value_type` 时依次为 `actual`/`target` |

每图 1–12 个类别（环形构成最多6类），1–3 个序列；构成和排名只有一序列。单位须相同；`metrics` 若带总体、指标定义，两者在整图必须一致。比较的业务可比性（例如组织范围或统计起点）仍由计划作者审阅。页面不能同时使用原参考7页 `chart` 与新 `data_chart`。

计划片段：

```json
{
  "data_chart": {
    "type": "trend",
    "categories": ["1月", "2月", "3月", "4月"],
    "series": [{"name": "演示季度服务次数", "fact_ids": ["m01", "m02", "m03", "m04"]}],
    "bounds_pt": [45, 135, 870, 340],
    "replace_shapes": ["8", "9", "10"],
    "reason": "以合成演示数据替换示例页的占位图形",
    "source_label": "数据来源：合成演示统计表",
    "interpretation": "四月达到阶段高点"
  }
}
```

此片段只说明字段，不能直接构建。`replace_shapes` 必须列全图表区域内的旧对象；参考4页通常为键8–45，旧文本仍需在 `slots` 逐个 `remove` 并写理由。`source_label` 要原样出现在可见来源槽位；`interpretation` 要出现在上屏文字或讲述备注。标题应说清该图证明的判断，纵轴自动使用指标单位。`bounds_pt` 以960×540pt画布计，不得遮盖品牌占位、标题、来源、结论或页码。新图表对象、工作簿、来源和解释会进入输出清单；旧演示图形不应残留在图后。

参考7页原环形图的 `chart`、参考5页原生 `ranking` 形状和各参考页 `bars` 仍可使用。它们适合忠实复用原型；新 `data_chart` 适合不同类别数和多序列数据。表面上的可编辑性有区别：`data_chart` 和参考7页的 `chart` 都可在 PowerPoint 编辑数据；`bars`/`ranking` 是可编辑形状，数值由计划重算，但没有“编辑数据”工作簿。

## 成片验收

对每张图先核对来源卡和结论：是否把“计划”画成“已完成”、是否用错分母、单位/时期/总体是否一致、环形图是否覆盖完整且互斥的整体。再在 PowerPoint 实际渲染图中检查轴起点、刻度、图例、标签拥挤、长类名和颜色含义。结构检查会核对内嵌工作簿、公式、缓存及源文件指纹；它不能证明解释是否合理。一个图看不清时，优先拆页、减少类别或改用已有原生页面，不能无限缩字。

公开仓库的合成样例仅用于演示数据绑定、可编辑图表和导出后检查。样例数据不对应真实业务，不得引用为实际报告结论。
