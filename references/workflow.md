# 内容组织与原生模板复用

## 叙事

先按 [叙事与排版](narrative-planning.md) 记录听众、讲述目标、意群、关系和预计时长，再选择原页。示例模板中的文字仅用于演示构图，不是新报告的默认结构。制度解读可能按“决策—依据—行动”、教师培训可能按“场景—选用—任务—反馈”，学生说明可能按“疑问—学习旅程—权益—待通知事项”组织。

每页有明确讲述作用。判断页可以写结论，流程页可以直接命名对象；证据说明限定范围，行动说明由谁、在什么条件下做。同一组照片或同一类项目可连续采用相同布局，但其递进关系要可说明。参考中的阶段判断和计划不能自动升级成本期已完成事实。

## 材料

- `primary`：本期口述稿，必须逐段有去向。
- `evidence`：用户提供且适用于本报告的图表、历史报告或文本证据。只证明“材料如此记载”，不自动证明原始统计正确。
- `reference`：样式、背景与原生对象，不允许将演示内容直接当作本期事实。

脚本校验原文件SHA并重新提取文本，避免账本与材料脱节。图片还需独立SHA、来源段落、真实照片声明及裁切。对“如图所示”而缺图表数据的段落，标记缺口，不能推算整张分布表。

表格数据按 [数据合同](data-contract.md) 建单元格账本；一个数在图表、结论和备注中应指向同一指标 ID。图表形式按 [证据图表](data-charts.md) 选择，先判断趋势/比较/排名/构成/进度是否有相应口径。只具备总数时直接呈现大数字，不能把数据贫乏包装成曲线。

含项目图片的 Word 按 [富图合同](media-assets.md) 提取 occurrence 并核对项目归属。自动匹配只是依据上下文的候选，冲突及不清楚的图进入待确认列表；一次出现对应一个处置记录，最终 PPT 中的照片与 DOCX 媒体 SHA 一致。

将缺口分为阻断与非阻断。关键数据、支撑结论的照片缺失为阻断；当前材料已能忠实表达但原始统计底表未提供，可记录为非阻断来源限制，不能写成独立核验通过。

## 版式选择

先查看目录和预览，再按听众要理解的关系选页面。照片用双图/三图变体；多项目用原生矩阵；排名每页最多17条；流程链按现有6步、12步等拓扑选页。增多时分页，减少时显式移除不用的文字和相应装饰，并视觉核查。原页指标数量和图标不构成内容要求；没有第四个有用的指标就删除第四组对象，不能拿弱相关数字凑格。不要用新造通用卡片覆盖原页面。

过渡在论点关系变化处决定，参见 [转场规则](transition-planning.md)。先检查相邻意群的听众问题，再用微转场、原生内容过渡或深色停顿页。插页必须有新增判断和时长来源；如只重复后页标题，就在备注中桥接。

原生对象保留完整主题、母版、布局、裁切、形状和段落XML。profile记录显式格式及容量提示，继承格式仍由原PPTX解析，不伪造统一默认值。正文长度只是早期提示，最终以PowerPoint实际测量和视觉检查为准。换用自己的模板时，必须重新提取对象映射；公开示例的对象ID不能直接套用于另一份PPTX。

## 审查

1. 内容：逐段覆盖；遗漏需写原因；推断/计划应保留语气；页内与备注不相互矛盾。
2. 数字：分母、单位、时间、名称、总体、实际/目标/估计身份、计算与颜色分组；原生图表值与工作簿一致，结论确由图中证据支持。
3. 素材：照片对应事件及源DOCX的具体出现位置；历史照片有明确时间身份；裁切不损害主体，歧义归属已确认。
4. 视觉：标题、数字与单位比例、背景、细线、文本边距、图片占比、连续页节奏。
5. 可编辑性：正文和流程是原生形状，参考环形图与新数据图表带内嵌工作簿；形状柱图可重算、但没有编辑数据工作簿；照片本身仍是位图。
6. 整套叙事：串读标题；判断听众问题是否得到回应、图式有没有把并列误画成流程、相邻页面有没有重复；核对详页与停顿页的节奏，以及备注中的过渡和限定。逐页通过不自动等于整套通过。

字号小于12pt不自动失败，因为参考稿即如此。新增实测超框超过1pt则阻断，先处理文字、槽位或分页，不直接缩字。例外仅限与本机基线相同引擎版本、原文及对象XML均未改变、超出量也与基线一致的原稿对象：记为待视觉复核的警告，而非自动放行。其字形必须完整、无邻接遮挡，逐页审查确认后才能交付。字体行高测量超出不等于实际字形被截断。实际渲染失败不能降格宣称最终通过。

Windows PowerPoint是验收引擎。WPS可编辑输出，但尚未等同于通过WPS渲染验收。Seqara网页画布的无损编辑不在本技能交付范围内；在Seqara调用本地CLI后打开原生文件编辑。
