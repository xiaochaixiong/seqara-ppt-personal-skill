# 根据讲述任务安排页面

本技能以仓库内的中性示例模板演示原生页面复用。页面变化服务于听众当下要理解的关系、作出的判断或采取的行动，不以轮换底图、强制改变版式或平均分配字数为目标。接入个人模板时，应以自己的原稿重新提取页面目录和对象映射。

## 先于选页的叙事记录

新材料先写一份简短的叙事记录，再选择参考页、创建 `plan.json`：

1. 写明听众、场合、预计时长，以及讲完后希望听众知道、判断或做什么。制度解读面向院校负责人、专业教师、学生时，不应仅替换称谓；负责人关注选用边界与决定，教师关注如何组织一堂课，学生关注参与、成果与权益。
2. 将口述稿拆成有来源的讲述意群。每个意群记录核心问题、一个可复述的结论或主题、来源及限定、作用（主张、证据、对照、过程、假设示意、边界、行动、转场等），并标明与前后意群的关系。`P1`等标记只是候选切分点；没有标记时也要由论证关系决定分屏。
3. 为每一页写下讲述角色、预计秒数、上屏所需证据、备注承担的解释、为何选这个原生构图，以及下一页为何接在这里。可将多段短意群放在一页，也可把一个关键意群拆成证据页和结论页；不要按段落数平均切页。
4. 先串读所有标题，再看联系表。只看标题若无法还原演讲主线，调整页面顺序与标题；连续高密度页若没有明确的比较或推进关系，精简、拆页或在真正转折处使用已有重点页。相同构图可用于课程清单这样的连续系列，须说明分组目的。

建议在生成计划中保存 `storyboard`（讲述意群、预计总时长及逐页分配），另记录听众、目标和来源；每页可附 `beat_ids`、`rhetorical_role`、`density_intent`、`estimated_seconds`、`selection_reason`、`transition_to_next`。`check-story` 会核验讲述意群覆盖、跨页分摊与总时长，接口见 [计划合同](plan-contract.md)。这些字段记录设计决策，方便内容修改后复查；程序对来源、数字和原生对象的验证不能代替对论证是否成立的判断。

## 用信息关系挑选原生页

先确认事实呈现的关系，再从 [页面目录](layout-catalog.md)挑原页。

| 要让听众看懂的关系 | 可参考原页 | 选用约束 |
| --- | --- | --- |
| 一个需要停顿的判断或信息缺口 | 17、25 | 深色页承载真实转折；标题与后续讲述应形成明确衔接。 |
| 一个总数与组成状态 | 3、28 | 每个数字都必须有来源、单位和适用范围。不要为填满四个指标槽加入次要数字；先考虑现有其他构图或同风格对象重排。 |
| 五个同级条目 | 8 | 适合真正并列的任务形式、原则等；职责交接、因果或先后步骤不应只因恰好有五项而套用。 |
| 两种边界或前后差异 | 23、29 | 两栏须有一致的比较轴；不能把两件无关事项硬作因果。 |
| 真正连续的环节 | 19、21、35 | 减少节点时保留阅读顺序、编号和箭头对应；周期、条件与并行职责不冒充时间顺序。 |
| 三个不同领域 | 22 | 原页可能带有具象图标；只有含义贴合时才保留。无关的三分类改选无图标构图。 |
| 三项由现状到行动的决定 | 26 | 箭头两侧须构成实际转向；图中留出的解释文字不能重复结论。 |
| 收束与可执行核对 | 38 | 结尾只保留听众能带走的判断或行动，避免与前一页重复整组要点。 |

标题不必一律写成判断句。证据页可写得到支持的结论，流程和背景页可直接命名对象。原页 1–37 的主标题槽须有可见文字；`purpose` 只是计划字段，不会自动显示在PPT上。

## 输出后的整套审阅

实际 PowerPoint 导出后，逐页检查格式、缺字、裁切和证据，再单独审阅整套演讲：听众问题是否在开场得到回应；标题串是否讲得通；流程、并列、对照、周期的图式有无误导；详页与简页是否各有作用；备注是否补足限定和转场；同一句行动建议是否在相邻页重复。记录具体页码与修订理由。屏显字数和预计时长只能提示异常，不能据此强制换版或宣称说服力合格。

整套审阅应特别留意四类常见失误：主标题槽位被清空；具象图标与内容类别不符；为了填满指标格而加入弱相关数字；连续多页流程图使听众分不清步骤、职责和时间。相应处理是补齐标题、换用语义合适的构图、删减多余指标并重排原生对象、把并列职责与连续步骤分开。检查**页内图式含义**与**跨页讲述推进**，不能只数用了多少种版式。
